# Episodic Summary Workflow

When this skill is active, follow these steps to archive a session:

1. **Note Creation**: Create a note in `ai/` named (Normal Text instead of kebab-case or snake_case) based on the keywords from the conversation that will be easy to search for or the user's specified name, following this template:

## Format
```markdown
## Summary
{Concise summary using **accurate, minimal, and literal wordings** (no filler).}

## Highlights
- {Leave blank for the user to manually input amazing insights or breakthroughs generated by the agent during the session.}

## Problems & Solutions
- **Problem**: {Clearly define the problem discussed or encountered.}
  - **Solution**: {Describe the solution or resolution reached for this specific problem.}
- **Problem**:
  - **Solution**:
- ...

## Related Notes
- {**Related Notes**: every note read during the session as wikilinks, preferably header reference/fragment link. Add keywords explaining why.}

## Original Prompts Reference
{Original link and all FULL User's prompt. DO NOT USE ... TO SKIP ORIGINAL PROMPT}
```
