## Summary
Critiqued the transition from Coretext v1 to v2, establishing that the current SQLite implementation with exact-match routing is brittle and will fail the TroRe v2 benchmark. Discussed and finalized the pivot from SQLite/JSON to an Event Sourcing architecture using an append-only JSONL file (`coretext.jsonl`) with pure Python glob-matching (`fnmatch`). Calibrated the TroRe v2 experiment prompts to ensure scientific fairness between the Control Group (Superpowers) and Treatment Group (Coretext v2). Formalized the standard nomenclature for D-SDD artifacts, replacing biological metaphors with systems engineering terms (e.g., `knowledge/` to `rules/`). Reaffirmed the philosophy of starting with market-tested prompts (Superpowers) and empirically discovering the optimal kernel constraints (`ARCHITECTURE.md`, `rules/*.md`) through continuous experimentation.

## Problems & Solutions
- **Problem**: Coretext v2's SQLite engine relied on exact file path matching, which would fail to inject context for newly created files during the TroRe v2 benchmark.
  - **Solution**: Pivot to pure Python glob-matching (`fnmatch`) to resolve `source` globs against modified file paths.
- **Problem**: A standard JSON array is prone to merge conflicts and formatting corruption when multiple agents append rules concurrently.
  - **Solution**: Adopt NDJSON/JSONL as an append-only Event Log (Event Sourcing).
- **Problem**: The Control Group in the TroRe benchmark was not explicitly prompted to explore architectural docs during the planning phase, making the test of "Constraint Amnesia" potentially unfair.
  - **Solution**: Adjusted the Control Group Planner prompt to explicitly mandate organic exploration of existing architecture docs, while keeping the Executor narrow and the Reviewer fairly triggered.
- **Problem**: The terminology used in Coretext (e.g., `experience.json`, `knowledge/`) relied on overly anthropomorphic "Hebbian brain" metaphors, clashing with the new OS/MMU paradigm.
  - **Solution**: Standardized the artifact nomenclature to reflect system constraints: `coretext.jsonl` (the event log router) and `rules/` (atomic constraints).
